Richards Systems : Cortext.io Extension

Created by Jefferson Richards, last modified on Jan 03, 2026

This extension can process the text from any english document. It is recommended you first copy and paste the text into a text editor (like Notepad, or equivalent) and then copy and paste, again, into the “Enter Text:“ field (to normalize encoding issues).

The document you send thru the Cortext Extension gets sent to the Event Cloud Dashboard - lined up with the daily news

 

  1. Download Extension from your link

  2. Unzip Extension in Local Computer

  3. Go to chrome://extensions in browser

  4. Select Developer Mode

  5. Select Load Unpacked

  6. Select dist-Barrett folder

  7. Pin Extension in Browser

  8. Note: if you do not want emails sent: type "no" here

 

 

Let me know if you have questions
